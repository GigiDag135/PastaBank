# PastaBank · CashMkr

CashMkr, l'app del bot PastaBank v1 (BTC, ETH, SOL, XRP su Hyperliquid), e il suo server.

- `index.html`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`: l'app, pubblicata su GitHub Pages (https://gigidag135.github.io/PastaBank/).
- `cashmkr-server.zip`: CashMkr Server per il server Oracle. Aggiornamento:
